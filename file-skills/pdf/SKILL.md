# PDF files

- Inspect page count, metadata and extractable text with `pdfinfo`, `pdftotext -layout`, `pypdf` or `pdfplumber`. Never assume extraction preserves page layout.
- Render relevant pages with `pdftoppm -f N -l N -png -r 150`. If extraction is empty or clearly incomplete, run `pdftoppm` then `tesseract image stdout -l chi_sim+eng` for OCR. Mark OCR uncertainty in the answer.
- Default to concise chat. Create a PDF only when the user explicitly requests one, and register `delivery: {format: 'pdf', detail: 'brief'|'standard'|'full'}` in the task plan.
- For new analysis PDFs, use `artifact.render_document`. It composes trusted HTML/CSS and exports with Chromium. Choose and order only the blocks needed to answer the question: summary, text, metrics, actions, callout, table, chart. The `ops-clean` theme controls typography, color, spacing and pagination; it does not prescribe business chapters, a cover, a country workflow or a minimum length. Do not add charts or sections to fill space.
- Use the published schema directly with the actual requested content; do not spend the task's render budget probing block shapes with test documents. All blocks have `id` and `type`, with optional `title`. Required content fields are: `summary: {text}`, `text: {paragraphs: string[]}`, `metrics: {items: [{label,value,note?}]}`, `actions: {items: [{proposal,priority?,object?,evidence?,conditions?,review?,confirmation?}]}`, `callout: {text,tone: 'info'|'warning'|'critical'|'success'}`, `table: {columns: [{field,label}],source}`, and `chart: {kind: 'line'|'bar',category_field,series: [{field,label}],source}`. `source` is `{evidenceId,rows_path,where,offset,limit}`; `limit` belongs inside `source`, never on the block. Tables use exactly one of `source` or `rows`; observed business data must use `source`. Charts never accept manually written values. These are API shapes, not required sections or an output template.
- Bind numeric observations and numeric object names with `fact_bindings` and `{{fact:id}}`. Bind tables with `source: {evidenceId, rows_path, where, offset, limit}` and columns `{field,label}`. Charts must use saved evidence via source, category_field and series fields; calculate or sort in analysis.table/python first. Do not handwrite chart values, mix units, infer missing values as zero or conceal partial coverage. Recommendations belong in actions fields and must be identifiable as recommendations.
- Text is displayed literally, without Markdown parsing. Use block `title` for headings, real `table` blocks for comparisons, `actions` for recommendations, and separate `paragraphs` for independent explanations. Never emit literal backslash-n as a line break. Summary/callout accept one short paragraph of at most 480 characters; use other components for lists, comparisons and detail. A long list or pipe-delimited pseudo-table inside a colored box does not create readable structure. These component constraints do not prescribe business chapters or their order.
- The host automatically adds document-local source references and a verification appendix from saved query/calculation lineage. Do not print evidence UUIDs, hashes, workspace paths or duplicate that appendix. Explain business definitions and comparison windows in the relevant content; identify stores and campaign IDs needed for an operator to find the objects. Source details may add pages; preserve their legibility rather than clipping or shrinking to an arbitrary page count. Do not invent upstream report names, UI routes, ownership mappings or URLs.
- The tool returns a PDF, its HTML source, actual PDF page previews and a draft_id. Inspect the page images using the task's image viewing capability; check relevant pages and every page of a short document. Use `artifact.revise_document` with the latest draft_id and local JSON pointer changes to fix layout or content. Submit only the latest PDF using `artifact.submit`; source and preview files are retained, not automatically delivered. A render receipt does not mean delivery.
- `artifact.render_report` remains for historical advertising drafts only. Use `pypdf` for page-level operations/forms, and LibreOffice for export from an existing editable source. Preserve source files. Reopen the actual final PDF to verify it.
- Render final pages and check legibility, alignment and missing content before `artifact.submit`. Preserve the source.

- Sources must describe the actual recorded provider, report/document, dates and selection in operator language. The host renders these as labeled source cards, not raw API/SQL fields. A provider may be any connected system or supplied file; never force it into a preset system name or invent a UI menu. Technical locators remain in the internal audit manifest.
- A numeric binding suffix permits only an empty string or `%`; write currency units in surrounding labels/text. A schema or binding correction must retain the user's requested diagnostic explanation and actionable recommendations. Never replace substantive analysis with a promise to analyze, internal rules, or empty section descriptions.
- Keep the requested comparison visible and verifiable: retain the key observations and source links for both periods when comparing periods. Correct bindings locally rather than deleting the comparison. Use short paragraphs or separate labeled items for different source conditions and data limitations; a single callout need not contain every caveat.
