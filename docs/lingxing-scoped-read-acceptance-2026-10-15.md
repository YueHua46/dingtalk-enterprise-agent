# 领星 MCP 用户店铺只读接入验收

验收日期：2026-10-15。本记录不含密钥、原始客户数据或用户身份凭据。

## 已交付

- `lingxing.read_scoped` 显式登记 36 个只读工具，覆盖广告、Listing、库存、产品表现、客服、退货、绩效、财务、促销与预警；完整清单以 `src/lingxing-read-registry.ts` 为准。
- 每次业务调用以当前 `corpId + userId` 刷新 CrossBorderOps 有效授权；身份不符、无授权、越权店铺、上游返回其他店铺均拒绝。
- 广告 SID 从官方店铺目录映射到 Profile ID，业务请求由宿主注入范围；不向模型暴露共享 action 执行通道。
- 能力目录提供中文业务描述；广告和经营分析 Skill 明确接口选择、参数类型、分页及数据口径。
- 证据保留来源、工具名、授权范围、实际请求参数、查询时间、上游分页与完整性限制。摘要按完整记录截取嵌套明细；完整响应存入任务证据文件。

## 验证结果

- TypeScript 构建通过；全量测试 79 个文件通过，907 项通过、1 项跳过。
- 36 个登记接口均进行真实调用：35 个成功返回，1 个返回领星内部错误。成功包括有效空结果，不代表所有接口都有业务记录。
- 德国 SID 240、日本 SID 242、美国 SID 222，各实测 9 项广告能力，共 27 次成功。区间为 2026-10-08 至 2026-10-14。
- 美国测试店铺的客户搜索词和关键词分析返回空；不能据此认定实际广告数据为零。
- 本机 gateway 已重建并部署；`/readyz` 返回 200。容器内再次实测授权店铺目录、客户搜索词及 Listing，返回来源为 `lingxing_mcp`，范围为所选授权店铺。
- 容器内 12,000 字符预算的 Listing 摘要保留所返回的两条完整明细及来源、范围、完整性元数据。额外复查中一次官方 Schema 请求返回无效工具结果，随后重试 Listing 成功；该现象尚未定位，不能承诺上游调用持续可用。
- 自动化验证覆盖当前用户调用分发、审计、权限撤销刷新、拒绝越权、上游错误、参数约束与证据摘要。尚未完成所有业务领域的自然语言对话端到端验收。

## 保留限制

- `finance_list_trade_reconcile`：真实调用返回领星“内部错误”，保留明确失败，不降级伪造数据。
- `query_fba_valid_list`：实测忽略单店过滤并返回跨店聚合，已禁止开放。
- 官方目录中其余接口尚未全部具备经过验证的用户店铺隔离；目录可发现不等于可执行。
- 不保证业务数据已完成全量采集：保留原始分页，禁止把第一页当作全部，禁止将广告汇总行与明细重复相加。
- 查询时间不等于业务更新时间；不同接口的币种、时区及归因窗口仍须核对。

真实调用摘要及原始结果保存在本机忽略目录 `tmp/lingxing-*-summary.json`、`tmp/lingxing-*.json`，不提交业务原始数据。
