## 方法

按用户授权，以当前唯一有效的石盛喜 DWS profile 显式发送到既有「钉钉AI Agent」群，真实 @ Agent 机器人，通过钉钉 Stream 接收任务，没有内部 API 注入。发送前核对群资料和机器人真实消息身份。新版 CLI 拒绝旧 openBotId 用作 @ 参数；第一次在客户端校验阶段被拒绝，`execution_started=false`。随后从群内实际机器人消息取得当前版本的 openDingTalkId，正确发送。

问题没有提及 A2UI、卡片、JSON、组件或布局，不追加要求模型使用某个工具，不人为替代 Agent 发送展示卡片。

## 结论与证据边界

真实消息回读中确认三条用户请求及对应机器人答复均在原群。数据库任务与审计记录确认三例 completed，A2UI 调用总数为 0。

核对产品比较任务的 Codex `session_meta.dynamic_tools`：模型实际收到 `a2ui` 命名空间的 `explain`、`present`、`show_sections`，排除工具未注册的情况。

本次样本量只有三例，不能推断所有任务均不会调用 A2UI。但结果没有证明自然采用 A2UI 的目标已经达成；“工具可用”与“模型主动采用”应分开验收。新 A2UI 发送、完结与客户端渲染没有被本轮自然测试执行，不能标记通过。
