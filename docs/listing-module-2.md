# Listing 模块 2：产品事实与出处

新增 `buildProductFactBook(prepared)`，消费模块 1 已绑定宿主来源的输入，返回带版本的事实表。纯代码，无模型、网络、文件读写或业务操作；尚未接入钉钉生成流程。

## 输入与输出

运营可以继续直接发文字或附件，无需固定模板。代码自动识别明确的“属性：值”行及分号分隔项，支持中英摄像头字段。任意自由段落留给后续提取适配器；本模块不猜事实。已整理的 statements 也可输入，但无明确属性标签的声明只能作为待核实候选。

事实记录属性、完整原始值、可支持的规范化数值、来源类型与引用、原文片段、字符位置、来源 SHA-256。事实 ID 和事实表版本可重复生成；资料变化会改变版本。字符位置相对于输入 material.content，不是原 PDF 页码或整个文档位置。

本品用户资料标记 user_provided（表示用户提供，不等于认证真实性）；当前 Listing 标记 page_unverified。竞品与评论不进入此产品事实模块，它们将在模块 4 作为市场参考单独处理。

## 数字与限制

支持 g/kg、mm/cm/m、秒/分钟/小时、Hz/kHz/MHz/GHz、个/件，以及单值、范围、最长、至少、约和尾随测试条件。使用十进制整数运算换算，避免浮点误差；只比较相同属性，不把充电时间当续航。不同限定条件同样触发澄清。

保留完整原文及限定条件，候选只提取“10 小时”时不会丢掉原始“最长”和测试条件。2K、4K、IP67、型号、连接组合不当作简单测量，不推算像素、认证或其他功能。温度、混合尺寸、不支持的单位和复杂数值格式保留原文，标为待核实。

未提供的字段列入 unknownAttributes，不补默认值。明确信息相等（例如 0.35 kg 与 350 g）不冲突；不同来源的属性、值或条件不同保留全部证据并要求澄清。模块 1 的文本冲突仅在本模块覆盖了该属性时由新的判断替代。

ready 表示已识别事实无已知冲突，不代表事实提取完整、资料充分、符合 Amazon 规则或允许发布。ready_limited 表示含页面声明或待核实候选。后续生成必须排除 conflicting 和未经核实的候选声明，不可把状态当成无条件发布许可。

## 样例与验收

`examples/listing/camera-product.txt` 是虚构摄像头资料，包含 12 项事实、费用与配件限制，故意不提供防护等级。

运行 `npm test -- tests/listing-input.test.ts tests/listing-facts.test.ts` 和 `npm run build`。测试覆盖中英字段、来源位置与哈希、单位等价、条件和否定保留、串属性、页面来源限制、未读资料、伪造片段、版本变化和未知数值格式。

本模块保证来源可追溯及受支持格式的标准化，不声称纯代码能理解所有自由文本语义；模型提取、平台规则和文案校验分别在后续模块完成。
