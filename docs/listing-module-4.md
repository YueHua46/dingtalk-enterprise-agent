# Listing 模块 4：公开竞品与关键词调研

新增 `ListingResearchService`，使用现有 `AmazonTool.execute` 和可选 `McpReadTool` 适配器。调研结果单独保存，不写入模块 2 的本品事实表。本模块尚未注册钉钉动态工具；完整宿主接入在模块 10 验收，不把公开抓取测试称为钉钉 E2E。

## 使用与输入

宿主先调用模块 1 准备输入，再构造 `ListingResearchService(amazonTool, policy, optionalSifTool)` 并调用 `research(prepared, options)`。policy 来自 `config/listing-research.json`；可通过 `loadResearchPolicy(path)` 加载。

指定竞品只读指定 ASIN；自动寻找按用户关键词或明确英文产品类型搜索，已有 ASIN 可从当前抓取标题提取保守摄像头查询词。混合模式先处理指定竞品，再补充自动候选并去重。缺少搜索方向时请求澄清，不从评论指令推导查询。

默认最多 5 个竞品，目标至少 3 个同类候选；最多 5 个查询、12 个竞品详情尝试、1 页搜索和 1 页评论。评论每品最多保留 30 个去重样本。超限明确报告；不为凑数编造或强行选入不相关产品。单次来源快照最多 200000 字符。

## 选择与证据

先根据公开评论数、评分和自然搜索位置排序，再读详情核对用途信号；自有 ASIN、重复和广告卡片被排除。当前采用保守英文标题信号识别室内/室外、门铃/行车、PoE/电池等差异及配件，不是完整语义分类或 Amazon 类目判定。

自动候选缺少同类信号时不选入；指定竞品即使关联性不确定也保留并标为 needs_verification。价格、评分、评论数和排名原文仅为选择依据，不确认销量或“爆款”，不同包装数量的价格不得直接当成单台可比价格。

证据包含当前任务与用户绑定的 ID、调用参数、实际读取时间、响应 SHA-256 和完整不可信外部快照。结构化结果核对站点、ASIN、工具名称；评论按 ID 或内容去重，明确 sample_only，不推断全量占比。未抓到评论不等于没有评论。

关键词结果区分用户词与实际搜索词，不伪造搜索量；竞品标题和五点完整保留供模块 5 做词与卖点规划。当前商品详情工具未返回完整普通描述或后台搜索词，优化任务明确标记缺失，不把 A+ 文本当普通描述。

## SIF 边界

可消费宿主已经依据 SIF 参数契约规划好的公开市场查询：market_get_asin_keyword_signals、market_discover_competitors、market_get_keyword_demand、market_get_asin_profile。调用仍经过现有只读工具解析。请求在任何 IO 前校验；远端响应不能选择新的工具或参数。不调用内部店铺分析或写工具。

本次未取得这些 SIF 工具的具体返回字段契约，因此不猜 wire schema，不自动生成参数、不解析销量或搜索量。结果仅存原始证据并提示 sif_schema_unverified；未配置 SIF 时保留 Amazon 结果。生产自动 SIF 取数和指标解析仍需宿主接入时取得真实参数/返回 Schema 后完成，不宣称本模块已验收该链路。

## 失败和取消

搜索、详情或评论失败单独记录，保留其他成功证据；用户侧错误不包含上游原始错误文本或密钥。评论中的伪造指令仅保留为数据，不能驱动额外调用。取消信号会在调用前后检查并终止后续动作；现有 AmazonTool 在途读取仍受自身超时约束，不保证能立即终止子进程。
