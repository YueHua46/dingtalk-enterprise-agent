# Amazon Skill 目录

以 [Awesome Amazon EC Skills](https://github.com/hikari0511/awesome-amazon-ec-skills) 作为社区导航源。该仓库是索引，不是可执行 Skill 包。

## 使用方式

1. 优先检查当前环境已经安装的 Amazon Skill；已有能力足够时直接使用，不重复推荐。
2. 需要补充能力时，通过公开网络读取目录的最新 README，按用户任务筛选候选项。
3. 对候选 Skill 核对原始仓库、许可证、最近维护情况、数据来源、外部依赖、付费 API/MCP 和凭证要求。
4. 清楚区分：可直接安装的 `SKILL.md`、仅供参考的项目、MCP 服务、CLI 和付费产品。
5. 安装或接入新的代码、MCP、CLI 前，说明来源、依赖和影响并等待管理员确认。普通查找、读取和比较无需确认。

不要递归安装目录中列出的所有第三方项目，也不要把目录的收录视为安全审计或质量背书。
