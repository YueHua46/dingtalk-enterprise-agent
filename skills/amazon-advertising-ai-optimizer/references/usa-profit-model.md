# 美国站利润模型和阶段规则

> 这是美国站运营经验资料，仅在用户问题涉及利润、CPA/CPC 或阶段策略时按需参考，不是固定 Workflow，也不是 Amazon 官方规则。

## 单 ASIN 模型

收集实际成交价、优惠、采购成本、头程、FBA 配送费、亚马逊佣金、退款、广告外成本和目标利润。不能用标价替代成交价，不能把广告销售额当净利润。

```text
P = 实际成交收入
M = P - 采购及物流成本 - 佣金 - 履约及其他可变费用 - 预期退货售后损失
R = 目标利润或风险储备
目标 CPA = M - R
保本 CPA = M
保本 ACoS = M / P
目标 ACoS = (M - R) / P
可承受 CPC = 目标 CPA × 预期 CVR
```

当任一输入未知时，输出未知或条件方案，不伪造利润结论。跨 ASIN、站点和币种不得混合计算。

当用户要求利润、CPA、CPC 或美国站阶段策略时，可按需参考 [美国原文](source-us.md) 的第八至十六部分及参数表。256.49 美元只属于原文示例产品；不得作为其他 ASIN 的默认价格。CTR、CVR、预算占比和调整幅度均为待验证测试假设，不能称为官方或行业标准。实际成交价、成熟归因和利润约束优先；M 或 M-R ≤0 时不输出盈利扩量方案。

零订单成熟花费 0.7/1.0/1.2 倍目标 CPA 分别触发复查/降价审查/暂停审查，不证明关键词统计无效；不使用统一“20 点击无单否定”。预算增加需至少 5–10 笔成熟订单、两个可比窗口 CPA 达标、预算受限及库存支持。每次只改一个主要变量。缺利润数据可提供明确标注假设的保守/基准/进取情景，不能断言盈利。

## 阶段策略

- 新品：优先收集相关流量和关键词，放宽短期 ACoS，但保留预算上限和止损线。
- 增长：把有订单和可接受 CPA 的搜索词转入更精确投放，逐步提高预算。
- 稳定：围绕目标 ACoS、利润和库存控制预算，优先处理高花费低转化对象。
- 爆款/放量：先验证库存、Buy Box、Listing 和边际利润，再逐步增加预算。
- 清货：允许更高的可接受 ACoS，但仍清理完全无关和高花费零订单流量。

## 必查维度

搜索词、关键词、ASIN 定向、广告位、Campaign/Ad Group 结构、预算消耗、库存、Buy Box、价格、优惠、评价和 Listing。每项动作写清调整值、复盘时间、止损线和回退条件。
