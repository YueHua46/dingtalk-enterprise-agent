# 德国站规则

> 这是德国站运营经验资料，仅在产品和样本条件得到核验时按需参考，不是固定 Workflow，也不是 Amazon 官方规则。

适用于 170–310 EUR 的监控摄像机安防套装。该类目决策周期长、订单稀疏，必须把加购率作为辅助指标，不能套用低价小商品阈值。

## 样本和动作边界

- 投放单元点击 < 15：标记“样本不足，不调价”，不做盈利/亏损判断。
- 搜索词点击 < 6：不建议否定，继续观察。
- 单次竞价调整只能在 -20% 至 +20%，最小变动单位 0.05 EUR。
- 同一投放单元连续两天不得调价；调价后观察至少 72 小时。
- 禁止一次性批量关停 3 个或以上活动；暂停只作为最后手段。

## 阈值

- 日均曝光 <800 为低曝光，800–<4000 为充足，≥4000 为高曝光。
- CTR ≥1.6% 优秀，1.0%–<1.6% 正常，0.5%–<1.0% 较差，<0.5% 极差。
- CVR ≥4.5% 优秀，3.0%–<4.5% 良好，1.8%–<3.0% 一般，0.8%–<1.8% 较差，<0.8% 极差。
- ACoS < 保本 ACoS 为盈利，保本至最大容忍 ACoS 为微亏，超过最大容忍为重度亏损。

## 场景动作

- 盈利且连续 3 天预算提前耗尽：建议预算 +10%–20%，竞价 +5%–15%。
- 盈利但 CTR <1.0% 或 CVR <1.8%：先查搜索词相关性，不盲目加价。
- 微亏且 CVR ≥1.8%：竞价 -5%–10%，预算维持。
- 重度亏损且有订单：竞价和预算各可 -10%–20%，不直接暂停活动。
- 累计花费 ≥售价 50%、点击 ≥15 且零订单：可建议暂停投放单元，但不直接关停整个活动。
- 低曝光且高度相关：竞价 +5%–10% 或预算 +10%–20%；相关性差则不抬价并建议否定。

## 德语搜索词

德语词独立维护，不能直接套用英文否定词。配件、单摄像头、替换件、支架、电池和线缆等无关词可作为候选，但必须引用实际搜索词证据。

- 花费 ≥售价 30%、零订单且与套装无关：精准否定建议。
- 花费 ≥售价 50%、零订单：精准否定建议。
- 花费 ≥售价 50%、有订单但非核心词 ACoS 超过最大容忍：短语否定建议。
- 曝光 ≥4000、CTR <0.5%、零转化且相关性差：短语否定建议。
- 核心词、点击 <6、花费 <售价 30% 零订单、微亏但有订单或加购率 ≥7%：保留观察。

新品测款保守否定、单次预算调整 ≤10%；清库存优先出单；稳定盈利严格执行 ACoS 和无关流量清理。
