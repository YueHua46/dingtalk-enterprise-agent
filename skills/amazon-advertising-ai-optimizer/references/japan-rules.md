# 日本站规则

## 基准和阶段

监控摄像头套装通常为 20,000–40,000 日元高客单价 3C 产品。7 天是常用分析周期，优化后在 7–15 天复盘。

### 新品期（上架 1–3 个月）

- 主要目标是关键词收录、相关搜索词发现和点击量，不严格考核 CVR 与 ACoS。
- CTR ≥ 0.5% 为合格；CVR 3%–5% 只作观察；ACoS 40%–60% 甚至更高可以接受，但必须标为阶段性容忍而非盈利结论。
- 自动广告日均点击目标 ≥ 20。点击不足时区分曝光不足和 CTR 低，再建议扩词、调整竞价或检查广告位。
- 搜索词先按相关性分为核心、可测试和无关；只对完全无关词建议否定。
- 低 CVR 先核查评价、价格、Listing 和决策周期，不因单一短窗直接否定高意向词。

### 成熟期（上架 3 个月以上）

- CTR ≥ 0.5% 合格、≥ 0.8% 优秀、< 0.3% 不合格。
- CVR 3%–5% 为高客单价电子类常用正常区间。
- ACoS ≤ 20% 健康，20%–40% 需要优化，> 40% 紧急处理。
- 日均点击 ≥ 20 为流量达标；品牌头条 CTR ≥ 1% 为合格。
- P0：ACoS > 40% 且花费高、CTR < 0.3% 或高花费零转化；P1：CTR 0.3%–0.5%、CVR < 3% 或日均点击不足；P2：ACoS 20%–40% 的优化机会。

## 五类分析

1. 新品广告分析。
2. 成熟期广告健康分析。
3. 优化前 7 天与优化后 7–15 天复盘：CTR/CVR 提升 ≥20% 或 ACoS 下降 ≥5% 可标为有效信号，仍需核对花费和样本量。
4. 搜索词治理：花费 > 5,000 日元且零订单的词按相关性决定精准/词组否定；CVR ≥3% 且 ACoS ≤20% 的词建议转入手动精准；有点击无转化的高客单词先观察。
5. 预算分层：S（ACoS ≤10% 且日均点击 ≥20）可增加预算；A（11%–15%）维持；B（16%–30%）观察/微调；C（>30% 或日均点击 <10）降低预算或暂停建议。保留 10%–15% 测试预算。所有预算、竞价和否定词只建议不执行。
