# 原文冲突和未定义口径

原文快照包括全部正文和表格，并附来源哈希。引用规则时给站点、原文章节或表格；不得把业务阈值称为平台官方规则。

- 日本成熟期正文规定 ACoS 20%–40% 需优化，表格写 30%–40%。使用正文覆盖连续区间，说明差异；预算分层的 10%–11%、15%–16% 等间隙保留“未定义”，不能四舍五入强行归类。ACoS 下降 5% 未说明百分点/相对值，复盘同时给相对变化及百分点，不据歧义单独判成功。搜索词出现不等于自然关键词已收录，没有排名/索引证据时写待验证。
- 德国微亏场景 2-2/2-3 条件相同而动作不同，不自动二选一；输出两个条件方案并要求补充风险偏好/历史变化。零订单的 30%/50% 花费边界存在重叠，优先保守观察并列出冲突，不把重叠规则重复执行。CTR 极差时禁止加价优先于低曝光扩量。原文加购率分母未定义，须确认来源口径，不把 Buy Box 占比当加购率。SB/SBV 不输出关键词否定或关键词层调价。
- 德国否定规则与新品/清货目标冲突时按目标采取保守保留；短语否定必须检查核心词根误伤，不能因为单词属于配件类别直接整根否定。
- 美国所有量化表为测试假设，实际成熟同 ASIN/意图/类型/广告位证据和利润、现金、库存约束优先。商品形态和技术类型分别建模；配件不套整套价格/利润。零分母展示未知或不适用，不能展示 CPA=0。汇总用分子/分母加总计算，不平均行比率。
- 历史调价时间未知时德国站不得给立即再次调价建议，先补记录；72 小时冷却按实际时间计算。
