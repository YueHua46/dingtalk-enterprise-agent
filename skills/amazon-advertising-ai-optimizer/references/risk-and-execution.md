# 风险和执行约束

建议与执行分离。分析阶段只输出可审查的变更计划；真实变更必须走宿主动态工具和当前会话确认。

每个写动作都要有：

- 幂等键：由当前用户、目标对象、动作类型、目标值和分析周期组成。
- 范围校验：目标店铺属于当前用户有效 SID 集合。
- 冷却检查：德国站同一投放单元 72 小时内不重复调价。
- 变更上限：德国站竞价单次 ±20%，新品预算按站点规则限制。
- 回执要求：只有工具返回成功回执才可报告执行成功。
- 失败处理：超时不自动重复写入，改为报告未知状态并等待核验。
- 审计：记录用户、目标对象、建议值、确认时间、实际回执和错误。

没有确认时使用“建议”“待确认”“未执行”。不得使用“已调整”“已暂停”“已添加否定词”等表述。
