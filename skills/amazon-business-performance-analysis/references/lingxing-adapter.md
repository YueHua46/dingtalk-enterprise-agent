# 领星数据适配

当前项目仅保留领星官方 MCP 的 `help` / `search` 目录能力。共享服务密钥的业务 `lingxing.action` 尚无法保证按当前钉钉用户的店铺范围裁剪，已从 Agent 工具列表撤下；旧会话调用也会被宿主拒绝。实时经营数据改用 `crossborderops.query`。本页仅用于解释用户主动提供的领星导出报表，不指导 Agent 直接调用领星业务工具。

1. 根据问题选择用户已经提供的最小范围报表：店铺/站点、销售或 ASIN 业务报告；必要时再补流量、库存、广告、利润/费用、Listing 状态。可用 `help` 或 `search` 查字段解释，不把目录查询当成经营数据。
2. 对导出报表核对店铺、站点、时间窗及数据来源；不要调用领星业务 `action`，也不要借用其他卖家身份。
3. 将返回值映射到 [数据口径](data-contract.md) 的概念。保留字段原名和来源，特别核查广告归因、父/子 ASIN、订单/发货日期、币种、时区、库存状态及最新刷新日期。没有字段定义时先查元数据/帮助；仍无定义就把该字段标为不确定。
4. 核对用户提供文件的分页、导出范围和完整性，只用于本次授权分析，不上传外部平台。
5. 若当前已授权后台数据和用户提供报表都缺少所需指标，在结果中说明缺失项；不把空响应解读成零销量。

按需优先顺序：

- “整体怎么样”：销售/订单及 ASIN 分布，随后仅补最可能影响结论的流量、库存或利润。
- “为什么销售下降”：两期销售与 ASIN 贡献，随后针对贡献最大的 ASIN 补流量/CVR、可售库存、Listing、广告与促销事件。
- “会不会断货”：当前可售库存、过去一段时间销量、已确认的在途数量和到货时间。
- “赚不赚钱”：销售、退款、平台费、广告、采购及物流成本；缺项列明覆盖范围。

领星报告不是 Amazon 的 Data Kiosk 指标。Amazon 官方 Skill 中的 `FBA_INV_VIS_*`、`SESSION_CNT` 等 ID 只说明分析意图，不可当作领星字段或请求参数。
